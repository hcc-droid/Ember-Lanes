# Ember Lanes — Antigravity Starter Files

1. Download and install Node.js LTS and Git for Windows.
2. Extract the `ember-lanes` folder.
3. Open the extracted folder in Antigravity IDE.
4. Open the terminal in the workspace and run `git init`.
5. Open Agent, select Planning mode, and ask the agent to read `AGENTS.md`, `docs/SPEC.md`, `docs/OPEN.md`, and `docs/DECISIONS.md`. The agent should analyze the files only and must not write any code yet.
6. Resolve the outstanding questions in `docs/OPEN.md` before completing P1.
7. Proceed through the following sequence: P1 → gate → P2 → gate → P3 → gate → P4 → gate → P5 → gate → P6 → gate. Assign only one phase at a time.

`AGENTS.md` contains the AI's project rules.

`docs/SPEC.md` describes the currently defined game rules.

`docs/OPEN.md` lists unresolved questions and decisions that still need to be addressed.

`.agents/skills/gate/SKILL.md` defines the project's verification and testing procedure.

**This starter package does not include any game code yet. P1 will create the project scaffold and source code.**
